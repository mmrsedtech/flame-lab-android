ساخت فایل APK بدون نصب Android Studio

۱. وارد github.com شوید و حساب ایجاد کنید یا وارد حساب خود شوید.
۲. گزینه New repository را انتخاب کنید. نامی مانند flame-lab-android بدهید و Create repository را بزنید.
۳. فایل ZIP حاضر را در رایانه Extract All کنید.
۴. در مخزن تازه، Add file > Upload files را انتخاب کنید و تمام محتویات داخل پوشه virtual-flame-lab-android را (پوشه‌های app، gradle، .github و فایل‌های دیگر) بکشید و رها کنید. مهم است محتویات در ریشه مخزن باشند.
۵. Commit changes را انتخاب کنید. ساخت خودکار با ذخیره فایل‌ها آغاز می‌شود.
۶. وارد زبانه Actions شوید، گزینه Build Flame Lab Android APK را انتخاب کنید. اگر ساخت خودکار شروع نشده، دکمه Run workflow را بزنید.
۷. پس از موفقیت اجرا (علامت سبز)، در صفحه همان اجرای Actions پایین صفحه به Artifacts بروید و Flame-Lab-APK را دانلود کنید.
۸. فایل دانلود شده ZIP است؛ از حالت فشرده خارج کنید. app-debug.apk آماده نصب آزمایشی روی گوشی است.

نکات:
- ساخت به اینترنت و دسترسی به مخازن توسعه نیاز دارد. اجرای خود اپ آفلاین است.
- این فایل APK نسخه آزمایشی debug است، نه نسخه امضاشده برای انتشار در فروشگاه‌ها.
- رایگان بودن/سهمیه استفاده از GitHub Actions به تنظیمات حساب و مخزن بستگی دارد.
- ساخت APK در این محیط اجرا نشده و تأیید نهایی منوط به اجرای Actions است.
- اگر ساخت با خطا متوقف شد، وارد اجرای ناموفق در Actions شوید و بخش Build installable debug APK را باز کنید.
