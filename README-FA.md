# آزمایشگاه مجازی شیمی؛ راز رنگ‌های شعله — نسخه اندروید

این پروژه، نسخه اندرویدی آزمایشگاه شعله پایه دهم است. کل محتوای HTML/CSS/JavaScript در فایل برنامه قرار دارد و اپلیکیشن **برای اجرا نیاز به اینترنت ندارد**. امکان نصب روی گوشی، فعالیت تعاملی، نگهداری محلی پیشرفت، شناسایی یون ناشناخته، چالش، آزمون و ثبت مشاهدات حفظ شده است.

## ساخت فایل APK در Android Studio

۱. پوشه `virtual-flame-lab-android` را از فایل ZIP استخراج کنید.
۲. Android Studio را باز کنید و گزینه **Open** را بزنید؛ همین پوشه را انتخاب کنید (نه فایل HTML).
۳. اگر Android Studio درباره Gradle پرسید، نسخه **Gradle 8.9** و Java / JDK **17 یا جدیدترِ سازگار** را انتخاب کنید. افزونه Android Gradle Plugin این پروژه **8.7.3** است. Android SDK Platform **35** نیز باید نصب باشد. برای نخستین ساخت، دانلود وابستگی‌های توسعه در رایانه لازم است.
۴. پس از همگام‌سازی پروژه، منوی **Build → Build Bundle(s) / APK(s) → Build APK(s)** را انتخاب کنید.
۵. خروجی معمولاً در مسیر `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد. این APK برای نصب آزمایشی مناسب است.
۶. فایل APK را به گوشی منتقل و با تأیید نصب از این منبع، نصب کنید.

**توجه:** این بسته حاوی پروژه کامل و فایل‌های منبع است؛ فایل APK کامپایل‌شده در آن نیست، زیرا ابزار Android SDK/Gradle در محیط ایجاد بسته در دسترس نبود. پروژه برای ساخت در Android Studio آماده شده اما روی اندروید واقعی در این محیط آزمون نشده است.

## مشخصات فنی

- ساختار: Android WebView + رابط بومی خروجی CSV / چاپ
- بدون نیاز به اینترنت در زمان اجرای برنامه، و بدون مجوز INTERNET
- فایل آموزشی اصلی: `app/src/main/assets/virtual-flame-lab.html`
- کد اندروید: `app/src/main/java/com/virtualflamelab/education/MainActivity.java`
- حداقل اندروید: Android 7.0 (API 24)؛ نیازمند نسخه به‌روز Android System WebView برای امکانات نوین مرورگر
- Android SDK: 35، Android Gradle Plugin: 8.7.3، Gradle: 8.9
- نام بسته: `com.virtualflamelab.education`
- بایگانی پیشرفت: فضای داخلی WebView در دستگاه، مبتنی بر `localStorage`، بدون همگام‌سازی ابری
- خروجی دفتر مشاهدات: انتخاب محل ذخیره فایل CSV توسط کاربر با سیستم فایل اندروید
- چاپ: سیستم چاپ اندروید؛ امکان ذخیره PDF هم در برخی دستگاه‌ها از طریق گزینهٔ چاپ وجود دارد
- دکمه بازگشت اندروید: ابتدا پنجره آموزشی را می‌بندد، سپس به خانه بازمی‌گردد و در نهایت درخواست خروج می‌دهد.

## ساخت نسخه انتشار

برای انتشار رسمی، از Android Studio گزینه **Build → Generate Signed Bundle / APK** را بزنید و یک امضای امن اختصاصی بسازید. نسخه debug فقط برای نصب و آزمایش است. در صورت انتشار عمومی، مراحل نهایی انتشار، آزمون روی دستگاه‌های مختلف، سیاست حریم خصوصی و بررسی الزامات فروشگاه را تکمیل کنید.

## ایمنی

شبیه‌ساز آموزشی است، نه مجوز انجام آزمایش واقعی. اجرای واقعی آزمون شعله فقط در آزمایشگاه مجهز، با نظارت دبیر و رعایت اصول ایمنی مجاز است.
